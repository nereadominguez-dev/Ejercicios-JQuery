# Ejercicios JQuery

Este repositorio contiene una serie de ejercicios prácticos desarrollados con jQuery para aprender y reforzar conceptos básicos de interacción con elementos HTML, eventos del usuario y manipulación del DOM.

Cada ejemplo muestra una funcionalidad sencilla pero útil para comprender cómo funciona jQuery en páginas web dinámicas.

## Objetivo

Practicar el uso de:

- Selectores de elementos
- Eventos del ratón y del teclado
- Modificación de estilos y contenido
- Inserción de contenido HTML
- Manipulación del DOM
- Interacción con formularios y botones

## Ejercicios incluidos

### Ejemplo 1 - Cambio de color de fondo
Se cambia el color de fondo de la página al hacer clic sobre un botón. Este ejercicio sirve para practicar el uso de eventos de clic y la modificación de estilos con jQuery.

### Ejemplo 2 - Cambio de color del botón al pasar el ratón
Cuando el cursor entra sobre un botón, este cambia de color; al salir, vuelve a su estado original. Se trabaja con los eventos `mouseenter` y `mouseleave`.

### Ejemplo 3 - Mostrar mensaje con doble clic
Al hacer doble clic en un botón, aparece un mensaje en pantalla. Este ejemplo demuestra cómo controlar eventos de doble clic y actualizar texto dinámicamente.

### Ejemplo 4 - Alerta al pasar el ratón
Al situar el cursor sobre el botón, se muestra una alerta. Es un ejercicio básico para entender cómo lanzar acciones al detectar interacción del usuario.

### Ejemplo 5 - Cambiar texto al salir del botón
Cuando el usuario abandona el botón, el texto de un elemento cambia para mostrar un mensaje. Se usa el evento de salida del cursor para modificar el contenido.

### Ejemplo 6 - Mostrar mensaje al enfocar el botón
Cuando un botón recibe el foco, se muestra un mensaje. Este ejercicio introduce el uso del evento `focus` y el comportamiento de elementos interactivos.

### Ejemplo 7 - Mostrar imagen
Al pasar el ratón por encima del botón, se inserta una imagen en la página. Se practica la inserción de contenido HTML mediante `html()` y la visualización de elementos adicionales.

### Ejemplo 8 - Reproducir vídeo
Cuando el cursor entra sobre el botón, se muestra un reproductor de vídeo. Este ejemplo permite aprender a cargar contenido multimedia en la página con jQuery.

### Ejemplo 9 - Mover el botón al presionar una letra
Se detecta la pulsación de la tecla `l` o `L` y, cada vez que se presiona, el botón se desplaza unos píxeles a la derecha. Aquí se practica el uso de eventos de teclado y movimiento de elementos en la página.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- jQuery

## Cómo ejecutar los ejercicios

1. Abre la carpeta del ejercicio que quieras probar.
2. Localiza el archivo `.html` dentro de esa carpeta.
3. Ábrelo en el navegador.
4. Interactúa con el botón o con la página para ver el comportamiento del ejemplo.

## Conclusión

Estos ejercicios forman una base muy útil para empezar a trabajar con jQuery y entender cómo crear interacciones dinámicas en páginas web de manera sencilla y visual.
